# BrahmShaktiHospital

Full-stack MERN hospital website and management system.

## Quick Start (Local)

```bash
npm run install:all
npm run dev:server
npm run dev:client
```

Frontend runs on `http://localhost:5173` and backend runs on `http://localhost:5000`.
